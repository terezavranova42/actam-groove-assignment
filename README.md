# Rebuild the groove

1. Open `solution.ipynb` and rebuild the groove with `drumkit.py`. Keep `play(...)` as the last cell.
2. Optional: `python3 check.py` runs your notebook the way the submission system does and writes `solution.wav`.
3. Commit and push. Copy the full commit id (SHA) from *Commits*.
4. Send the repository URL and the SHA by email, as explained on the course page: https://actam.bruschi.dev/lesson-04/drum-submit/
